One single-line joke excusing a missed deadline for make.fun's "One Line, No Deadline Met" bounty: my Wi-Fi died at 4:58, two minutes before the deadline, and the router's help page told me to check my internet connection.

## Run it

```sh
python3 main.py
```

Writes the joke to `/output/entry.txt` (override with `OUTPUT_DIR`).
